# Bike Sharing Visualization (VS Code)

## Setup
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run
- **Cell by cell:** open `bike_visualization.py` in VS Code, install the *Python* + *Jupyter* extensions, and click **Run Cell** above any `# %%` marker (plots show in the Interactive Window).
- **Whole script:** `python bike_visualization.py` (each plot opens in a window; close it to see the next).

The dataset downloads automatically into `./data` on first run.
